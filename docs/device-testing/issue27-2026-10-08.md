# Issue #27 真机验收 — 2026-10-08

华为 DBR-W00，Android 12 / API 31，USB ADB 5037，横屏 2560 × 1600、400 dpi。验收运行同一份生产代码的独立 debug 包 `com.example.claudephonemonitor.issue27test`，避免并行安装覆盖日常应用。设备实装 APK 与本地构建 SHA-256 一致：`00089b6c87e9b9c16a7f6bb5d2ddc4ca3cc09b1cda9bd5dfc3a2e4c641143842`。

15 个不同真机用例均取得通过结果。最终全量运行耗时 70.931 秒，14/15 通过；唯一的 5 秒计时用例中途丢失 Compose 测试窗口，保持原断言定向重跑后 1/1 通过，耗时 6.125 秒。这不是一次全量零失败的记录。

## 验收结果

- 完成页面的大字、会话行及无障碍状态均使用 `DONE`，不显示 `FINISH`。真机截图的标题和行分别含 127,108、994 个精确 `#93BE81` 绿色像素。短横屏、大字号及五行会话布局均通过。
- 生产单调时钟实际驱动 5 秒弱提醒和 15 秒强提醒。Relay 的五秒 `recent_completion` 到期后，Alpha/Beta 的 `task_completed` 仍为真；强提醒到期返回列表后，两行仍为绿色 DONE。首个观测点到强提醒退出为 14,943 毫秒，测试按初始剩余时间核对原截止，不将该观测差当作完整提醒时长。
- 生产 WebSocket 经实际断开、重连后保留 DONE；新建没有完成缓存和事件游标的 ViewModel/客户端，也能从权威快照恢复 DONE，且不重播已过期提醒。执行中和等待中的会话显示各自状态，从未开始的会话及失败任务不会获得 DONE。
- 同一 Alpha 会话再次开始任务时显示 WORKING，等待时显示 WAITING，完成后再次显示 DONE，其他已完成行继续保留 DONE。

`DoneRelayDeviceTest` 通过真实 Android、生产 `WebSocketMonitorClient`、`MonitorViewModel`、Compose、Collector 和配对 SQLite Relay 执行上述链路。输入是安全合成事件，长任务的源时间戳合成了 300,001 毫秒持续时间；提醒计时没有注入或跳时。新的 ViewModel/客户端恢复不等同于手机应用进程死亡测试。

## 真机发现并修正的问题

第二个短任务完成后，快照曾将仍在计时的 Alpha 强提醒名称改为 Beta。完成事实已经独立保留，但提醒标题更新仍错误地跟随最新完成记录。现已按当前提醒的会话、完成序列及兼容的任务 ID 约束标题更新，保留 Alpha 的身份和原截止；Beta 继续独立保留 DONE。

补充 JVM 回归后，Android 194 项测试中 193 项通过、1 项真实录制测试按条件跳过；lint 零错误、九条警告。默认及独立包 APK 均构建通过，新增 fixture 的 ESLint 检查通过。真机原有 Alpha 名称断言保持不变，并已通过。

## 复现与清理

构建后端并在独立终端保持 fixture 运行：

```bash
npm run build
DEVICE_TEST_PORT=18887 node tests/device-done-relay.mjs
```

另一终端构建、安装及执行，需已配置 JDK 21、SDK 35、ADB：

```bash
./gradlew --offline --no-daemon -PdeviceTestApplicationIdSuffix=.issue27test :apps:android:assembleDebug :apps:android:assembleDebugAndroidTest
adb -P 5037 install -r apps/android/build/outputs/apk/debug/android-debug.apk
adb -P 5037 install -r apps/android/build/outputs/apk/androidTest/debug/android-debug-androidTest.apk
adb -P 5037 reverse tcp:18887 tcp:18887
adb -P 5037 shell am instrument -w -r \
  -e class com.example.claudephonemonitor.ui.MonitorReferenceTest,com.example.claudephonemonitor.ui.ReminderTimingDeviceTest,com.example.claudephonemonitor.ui.DoneRelayDeviceTest \
  -e deviceRelayUrl http://127.0.0.1:18887 -e timeout_msec 180000 \
  com.example.claudephonemonitor.issue27test.test/androidx.test.runner.AndroidJUnitRunner
```

保持设备唤醒。完整重跑前重启 fixture，重新建立合成生命周期。结束后对 fixture 按 Ctrl-C，删除专用 USB 映射和独立应用：

```bash
adb -P 5037 reverse --remove tcp:18887
adb -P 5037 uninstall com.example.claudephonemonitor.issue27test.test
adb -P 5037 uninstall com.example.claudephonemonitor.issue27test
```

本轮清理已核实：18887 无监听，临时 fixture 目录、独立测试包及 USB 映射均已移除，充电常亮设置恢复原值 0，日常 `MainActivity` 在前台。配对、用户 Hooks 和常驻后端配置保持原样。本地最终 APK 已重新构建为默认应用包名。
