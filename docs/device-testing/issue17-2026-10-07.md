# Issue #17 真机调试记录 — 2026-10-07

设备为华为 DBR-W00，Android 12，横屏 2560 × 1600。覆盖安装 Debug APK 和测试 APK，保留了原应用数据与配对。测试期间设备识别 USB 供电为 AC，临时启用充电时保持唤醒；结束后恢复原值 0。清理隔离服务和 USB 端口映射后，日常 `MainActivity` 已重新打开并显示 `RELAY CONNECTED`，原配对文件仍在；真实会话画面未归档。

真机仪器测试验证了三段路径：

- `ReminderTimingDeviceTest` 2 项通过（23.312 秒）。经生产 wire 解析器、`MonitorViewModel`、单调时钟计时器和 Compose 界面，300,000 毫秒完成事件保持 Status 页并显示约 5 秒弱提醒；300,001 毫秒完成事件在 Usage 页上方显示约 15 秒强提醒，后续弱工具失败不延长截止时间，到期恢复 Usage 页。两项都冻结 Compose 动画时钟，以确认到期由真实单调时钟驱动。
- `MonitorReferenceTest` 9 项通过（最终版 12.268 秒）。覆盖弱提醒在 Status/Usage 页不切页、强提醒覆盖 Usage 页、主会话列表和名称、短横屏五行可见及大字号可滚动到末行。合成任务真机截图：[Status 弱提醒](screenshots/issue17-2026-10-07/weak-status.png)、[Usage 弱提醒](screenshots/issue17-2026-10-07/weak-usage.png)、[Usage 上方强提醒](screenshots/issue17-2026-10-07/strong-from-usage.png)。
- `SubagentRelayDeviceTest` 1 项通过（12.282 秒）。设备上的生产 WebSocket 客户端连接本机隔离的生产 Collector、Codex watcher 和 SQLite Relay，使用临时目录中的合成 rollout。短主任务完成约 5 秒弱提醒，后续子代理完成、失败与等待没有覆盖主任务名称或重置截止时间；重连后没有恢复子代理提醒。测试没有读取或改动用户的 Codex 会话。

首次页面测试期间设备自动熄屏，导致 Compose 窗口丢失、测试偶发失败；保持唤醒并等待界面根节点完成布局后，整套测试通过。Gradle 的 `connectedDebugAndroidTest` 因 Google Maven 测试平台组件下载时 TLS 握手失败而无法启动，测试 APK 已成功构建，以上结果均通过 `adb shell am instrument` 在同一设备上直接运行。

强提醒的真机计时验证使用合成 wire 事件；真实 WebSocket 链路验证使用短任务。长任务失败、明确等待和断连的分级仍由 JVM 测试覆盖，未在此轮设备测试中逐一触发。
